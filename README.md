# 行動撲滿

一款依照「今日可用體力」安排任務的本機優先 PWA。它將完成任務累積為工作分，並在主動結算時把剩餘體力收回為享樂體力。

## 目前功能

- 每日首次開啟時設定 0–100 體力
- 三類任務：一定要執行、可拖延、可無限推遲
- 依優先程度、期限與剩餘體力自動安排
- 完成或今天放棄任務
- 隨時修正剩餘體力並重新安排
- 主動結算與跨日自動結算
- 工作分、享樂體力及每週平衡倍率
- 每日紀錄與每週成績單
- JSON 資料備份
- 離線使用與加入 iPad 主畫面

## 本機開啟

Service Worker 需要透過 HTTP 執行，可使用任意靜態檔案伺服器。例如：

```bash
npx serve .
```

資料目前只保存在瀏覽器的 `localStorage`，不會上傳至伺服器。請定期從設定匯出 JSON 備份。
